# CeX: арбитраж в Ирландию

Ищет товары, которые дешевле купить в CeX другой страны (UK / ES / PT), чем CeX Ирландия платит за них кэшем.
Ещё ищет аномалии в Ирландии, где кэш близок к цене продажи.

## Как пользоваться
1. Открой в обычном браузере `https://ie.webuy.com`, затем F12 → Console. Вставь содержимое `cex-scan.js` и нажми Enter.
   Скрипт пройдёт по категориям Phones и Gaming (5–20 минут) и скачает `cex-ie-ДАТА.json`.
2. То же самое на `uk.webuy.com`, `es.webuy.com`, `pt.webuy.com`.
3. Открой `compare.html` локально и загрузи все JSON-файлы.

Товары сопоставляются по `boxId`. Это один артикул CeX и один грейд (A/B/C), поэтому сравнение честное.

## Цены с eBay (`ebay_prices.py`)
Берёт файл `cex-ie-*.json` и для каждой модели ищет на eBay DE/FR/IT/ES/NL самые дешёвые лоты «Купить сейчас».
Учитываются только продавцы из этих стран (ЕС, без таможни), которые доставляют в выбранную страну. Цена считается с доставкой.

1. Получи ключи: https://developer.ebay.com → Application Keys → Production keyset. При создании eBay спросит про Marketplace Account Deletion: выбери «not persisting eBay data / exempt».
2. Запусти (Python 3.8+, ничего ставить не нужно):
   ```bash
   export EBAY_APP_ID=твой_Client_ID
   export EBAY_CERT_ID=твой_Client_Secret
   python3 ebay_prices.py cex-ie-2026-11-24.json --min-cash 60 --ship-to IE
   ```
   `--ship-to` — страна, куда закажешь посылку. Если отправлять сразу на ирландский адрес (друг, пункт выдачи, почтовый форвардер), лететь с вещами вообще не нужно.
3. Получишь `cex-ebay-ДАТА.csv` (открывается в Excel, отсортирован по прибыли) и `cex-ebay-ДАТА.json` (загружается в `compare.html`).

Как считается цена eBay: отбрасываются чехлы, коробки, «defekt / for parts» и чужие модификации (Pro, Mini, Lite и т.п.).
Затем берётся **3-я по дешевизне** цена (`--pick`): самая дешёвая часто оказывается мусором или скамом. В CSV также есть минимум и медиана 5 лотов.
Это цены **активных** объявлений. Реальные цены продаж (sold) официальный API не отдаёт, их можно проверить вручную на eBay: фильтр «Verkaufte Artikel».

## Важно
- UK не в ЕС. Товар для перепродажи нужно декларировать на таможне Ирландии (НДС 23% + пошлина). Без декларации разрешено только €430 личных вещей.
  ES/PT → IE это внутри ЕС, таможни нет.
- Цена выкупа зависит от остатков магазина и меняется ежедневно. Перед поездкой сверь цену на сайте и в конкретном магазине.
- Если регулярно сдаёшь технику, CeX может ограничить приём. Налоговая может посчитать это торговлей.
