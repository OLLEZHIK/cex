# CeX: арбитраж в Ирландию

Ищет товары, которые дешевле купить в CeX другой страны (UK / ES / PT), чем CeX Ирландия платит за них кэшем.
Ещё ищет аномалии в Ирландии, где кэш близок к цене продажи.

## Как пользоваться
1. Открой в обычном браузере `https://ie.webuy.com`, затем F12 → Console. Вставь содержимое `cex-scan.js` и нажми Enter.
   Скрипт пройдёт по категориям Phones и Gaming (5–20 минут) и скачает `cex-ie-ДАТА.json`.
2. То же самое на `uk.webuy.com`, `es.webuy.com`, `pt.webuy.com`.
3. Открой `compare.html` локально и загрузи все JSON-файлы.

Товары сопоставляются по `boxId`. Это один артикул CeX и один грейд (A/B/C), поэтому сравнение честное.

## Важно
- UK не в ЕС. Товар для перепродажи нужно декларировать на таможне Ирландии (НДС 23% + пошлина). Без декларации разрешено только €430 личных вещей.
  ES/PT → IE это внутри ЕС, таможни нет.
- Цена выкупа зависит от остатков магазина и меняется ежедневно. Перед поездкой сверь цену на сайте и в конкретном магазине.
- Если регулярно сдаёшь технику, CeX может ограничить приём. Налоговая может посчитать это торговлей.
